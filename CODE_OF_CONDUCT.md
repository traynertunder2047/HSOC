# Code of Conduct

Ci si aspetta comunicazione rispettosa, inclusiva e costruttiva. Non sono accettati molestie, minacce, discriminazioni, divulgazione non autorizzata di dati personali o comportamenti intimidatori.

Le segnalazioni possono essere indirizzate ai maintainer del repository. Prima della pubblicazione, indicare nel repository un contatto di moderazione effettivamente monitorato.
